# 반도체 공정 데이터를 활용한 장비 이상 감지

공정 센서 데이터로 불량을 사전에 감지하는 프로그램과 실시간 모니터링 화면을 구현하는 프로젝트.

> 영남대학교 도전학기제 2026학년도 2학기 · 도전학기(2) 3학점
> 융합화학공학전공 김재민 · 지도교수 이진태

---

## 문제 정의

반도체 공정에서는 장비마다 수백 개의 센서가 온도·압력 등을 끊임없이 측정한다.
이 값이 평소와 달라지면 불량품이 발생하거나 장비가 고장 나기 쉽지만,
사람이 수백 개 센서를 눈으로 보고 이상을 판단하기는 어렵다.

이 프로젝트는 센서 데이터로부터 이상을 자동 감지하는 모델을 만들고,
서로 다른 계열의 감지 기법을 동일한 기준으로 비교한다.

## 왜 어려운 문제인가

| 발견 | 의미 |
|---|---|
| 불량률 **6.64%** (1,567개 중 104개) | 극단적 클래스 불균형 |
| "전부 정상" 예측 시 정확도 **93.36%** | **정확도는 이 문제에서 무의미한 지표** |
| PCA 상위 2개 주성분 설명력 **9.7%**, 불량-정상 미분리 | 단순 선형 분리로 판별 불가 |

따라서 평가는 정확도가 아닌 **재현율(Recall) 중심**으로 설계했다.
목표는 실제 불량의 85% 이상 감지이며, 그에 따르는 정밀도 저하를
비용 관점에서 함께 분석한다.

## 데이터

**SECOM** — 2008년 실제 반도체 제조 라인의 공정 센서 기록

```
McCann, M. & Johnston, A. (2008). SECOM [Dataset].
UCI Machine Learning Repository. https://doi.org/10.24432/C54305
```

- 측정 1,567건 × 센서 590개 + 합격/불량 라벨
- 결측이 있는 센서 538개, 값이 변하지 않는 센서 116개

두 번째 데이터셋(UCR Wafer, 공정 센서 시계열)으로 파이프라인의 일반성을 검증할 예정.

## 전처리 파이프라인

```
원본 1,567 × 590
  ├─ 상수 센서 제거              −116
  ├─ 결측 50% 초과 센서 제거      −28   →  446개
  ├─ 층화 분할 8:2                     →  학습 1,253 / 시험 314
  ├─ 중앙값 대치 (학습셋 기준)          →  결측 10,868 → 0
  └─ 표준화 (학습셋 기준)              →  평균 0 · 표준편차 1
```

**분할을 대치·표준화보다 먼저 수행**하여 데이터 누출(data leakage)을 방지했다.
모든 변환기는 학습 데이터에만 `fit`하고 시험 데이터에는 `transform`만 적용한다.
시험 데이터는 최종 성능 측정 1회에만 사용한다.

## 중간 결과 — 방법 5종 비교

학습 데이터(1,253개 · 불량 83개) 내 5겹 층화 교차검증. 시험 데이터는 사용하지 않음.

| 방법 | 계열 | 잡은 불량 | 놓친 불량 | 헛알람 | Recall | Precision | PR-AUC | ROC-AUC |
|---|---|---|---|---|---|---|---|---|
| 로지스틱 회귀 | 지도 | 17 | 66 | 90 | 0.205 | 0.159 | 0.123 | 0.618 |
| 랜덤 포레스트 | 지도 | 0 | 83 | 0 | 0.000 | 0.000 | **0.178** | **0.713** |
| XGBoost | 지도 | 3 | 80 | 8 | 0.036 | 0.273 | 0.151 | 0.668 |
| Isolation Forest | 이상탐지 | 10 | 73 | 73 | 0.120 | 0.120 | 0.104 | 0.542 |
| One-Class SVM | 이상탐지 | 17 | 66 | 113 | 0.205 | 0.131 | 0.091 | 0.546 |

무작위 수준: PR-AUC 0.066 / ROC-AUC 0.500

**세 가지 발견**

1. **랜덤 포레스트는 전체를 "정상"으로 예측했다.** `class_weight='balanced'`를 적용했음에도 잡은 불량 0개. 정확도로 평가하면 93.4%로 1위지만 실용성은 없다. 불균형 데이터에서 정확도가 왜 무의미한 지표인지 보여주는 사례.

2. **그러나 같은 모델의 PR-AUC가 최고(0.178)다.** 판정과 순위 매김이 분리된 것으로, 위험도 순위는 가장 잘 매기지만 판정 임계값(기본 0.5)이 과도하게 높아 이를 넘는 표본이 존재하지 않는다. → 모델 교체가 아닌 **임계값 조정**이 해법.

3. **이상탐지 계열이 지도학습보다 열등하다.** ROC-AUC 0.542 / 0.546으로 무작위(0.5)에 근접. 주성분 분석에서 불량이 별도 군집을 형성하지 않은 결과와 일치하며, "불균형 데이터에는 이상탐지가 유리하다"는 통념이 성립하지 않는 사례다.
